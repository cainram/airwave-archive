Convert library files

Advanced: this changes your library. Each ticked file is converted where it is, in its folder. Once the new file has been made and checked, it takes the original's place and the original file is deleted for good. Only your backups can bring it back, so make sure you have one. The episode's details, your listening place, groups and feeds stay with the new file.

These recordings are in formats that browsers, iPhones and podcast apps don't all play (video files, RealAudio, WMA, Ogg, Opus, and large lossless FLAC, WAV and AIFF files). Sound that's already MP3 or AAC is copied unchanged; the rest becomes MP3. Files you add through the Inbox are converted there instead.
