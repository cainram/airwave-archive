Bring in details from an episode log: a spreadsheet saved as a CSV file (in Excel or Numbers: File → Export / Save As → CSV). The first row should name the columns, for example Series, Date, Title, Cast, Notes.

{# hx-boost="false": a download, not a page to show. #} ⬇ Download an example spreadsheet Every column the app understands, with one example row to replace. Open it in Excel or Numbers, fill it in, and save it as CSV again.

Each row is matched to an episode in your library by its file name (if there's a File column), or else by its series and air date, or series and episode number. You'll see a preview first; nothing is saved until you say so.

If the spreadsheet has no Series column (a log for one show often doesn't), type the series here and it's used for every row.
